## Overview

Elden Ring Trainer targets Windows players who want a small helper for Elden Ring. It exposes controls for a few core session values: runes, health, and stamina.

The design stays narrow on purpose. Instead of packing in many unrelated tools, it concentrates on quick, local value edits during a play session.
